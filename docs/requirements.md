# Требования к системе бронирования отелей

## 1. Назначение системы

Система предназначена для автоматизации процесса бронирования номеров в отеле:
приёма заявок от гостей, контроля загрузки номерного фонда, проведения оплаты
и формирования отчётности для службы приёма и размещения.

## 2. Функциональные требования

1. Система должна обеспечивать создание, редактирование и отмену бронирований.
2. Система должна отображать шахматку номерного фонда в реальном времени.
3. Система должна поддерживать интеграцию с платёжным шлюзом.
4. Система должна формировать отчёты по загрузке и выручке.
5. Система должна поддерживать роли: администратор, менеджер, горничная.

## 3. Нефункциональные требования

- Доступность сервиса бронирования — не ниже 99,5 % в месяц.
- Время отклика на операцию создания брони — не более 1 с при 95-м перцентиле.
- Хранение персональных данных гостей — в соответствии с 152-ФЗ.
- Резервное копирование базы данных — ежедневно.
