# Архитектура системы бронирования отелей

## 1. Общая схема

- **Тип:** веб-приложение (клиент-сервер).
- **Backend:** Python (FastAPI).
- **Frontend:** React.
- **База данных:** PostgreSQL.
- **Интеграции:** платёжный шлюз, модуль онлайн-оплаты, email-сервис.

## 2. Компоненты системы

| Компонент | Назначение | Технология |
|---|---|---|
| Web-клиент | Интерфейс администратора и менеджера, шахматка номерного фонда | React, TypeScript |
| API-сервис | Бизнес-логика бронирования, REST-эндпоинты | Python, FastAPI |
| Хранилище данных | Бронирования, номерной фонд, гости, платежи | PostgreSQL |
| Платёжный модуль | Приём оплаты и возвратов | Платёжный шлюз (API) |
| Сервис уведомлений | Письма гостям о подтверждении и отмене брони | SMTP, email-сервис |

## 3. Схема взаимодействия

```
[React SPA] --HTTPS/REST--> [FastAPI] --SQL--> [PostgreSQL]
                               |
                               +--> [Платёжный шлюз]
                               +--> [Email-сервис]
```

## 4. Ключевые сущности данных

- **Guest** — гость (ФИО, контакты).
- **Room** — номер (категория, вместимость, стоимость).
- **Booking** — бронирование (гость, номер, даты заезда и выезда, статус).
- **Payment** — платёж по бронированию.
