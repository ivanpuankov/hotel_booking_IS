# АИС «HotelBooking» — система бронирования отелей

Проект представляет собой автоматизированную информационную систему для управления
бронированиями номеров в гостиничном комплексе. Система позволяет создавать и отменять
брони, управлять номерным фондом, проводить оплату и формировать отчёты.

## Структура папок

```
hotel_booking_IS/
├── docs/            # документация (требования, архитектура)
├── management/      # управленческая информация (план проекта, регламенты)
├── src/             # исходный код
├── tests/           # тесты
└── README.md        # описание проекта
```

## Как запустить

1. Установить Python 3.11+.
2. Запустить `python src/main.py`.
3. Запустить тесты: `python -m pytest tests/`.
